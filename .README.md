# My Python Utilities

This project contains a collection of useful Python functions bundled into one file.

## 🚀 Features
- Math functions: add, subtract, multiply, divide, factorial, fibonacci, prime check
- String functions: reverse, palindrome check, vowel count
- List functions: max, min, average
